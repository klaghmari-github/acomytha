# TREE-DIF-039 — La balle rouge de Victorino, jusqu'au portail

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Victorino veut faire rebondir sa balle rouge jusqu'au portail avec Aniss. T1 = balle rouge / sac à pois / gourde bleue (les trois partent). T2 = flaque (eau, ronds) / banc du tilleul (rebonds) / muret du portail (course). T3 = neuf résolutions (jouer dans l'eau, attendre la goutte, main de papa ; sauter ensemble, attendre le tour, goûter de maman ; relais de balles, attendre le portail, rythme de papa). L'élan d'Aniss se vit, sans slogan. Fin : le portail.
