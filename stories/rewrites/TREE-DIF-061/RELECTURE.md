# TREE-DIF-061 — Le moulin de papier d'Aniss et la grille de l'école

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Aniss veut planter son moulin de papier dans la grille de l'école. T1 = moulin / fil / caillou (les trois partent). T2 = grille (barreaux trop serrés) / caniveau (eau trop vite) / porche (air trop calme). T3 = neuf résolutions (bas, tendre le moulin, crochet ; dalle, fil, bord ; vent, mains de Mila, nœud). Aniss répond avec les mains, sans étiquette. Mila attend, tend. Fin : le moulin tourne, on entre.
