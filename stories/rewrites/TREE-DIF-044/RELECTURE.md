# TREE-DIF-044 — Les groseilles de Raphaël au treillis

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Raphaël veut remplir un bol de groseilles rouges pour le goûter. Sarah arrive, lunettes encore floues, cheveux mouillés, ciré jaune trop long. T1 = bol blanc / panier d'osier / nappe à carreaux (les trois partent). T2 = serre (buée sur les verres) / tilleul (mèches dans les feuilles) / treillis (manches trop longues). T3 = neuf résolutions (torchon, mains, pas hors de la serre ; élastique, serviette, tenir le bol ; manches, Raphaël tient, nouer les poignets). On cueille ensemble, sans slogan. Fin : le bol rentre, tout rouge.
