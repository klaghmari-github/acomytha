# TREE-DIF-052 — Le phare de coquillages de Mila

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Mila veut un phare de coquillages sur le rocher, avant la marée. Sarah arrive, lunettes voilées d'eau, cheveux collés de sel, ciré trop long. T1 = clochette / seau bleu / pelle jaune (les trois partent). T2 = jetée (eau sur les verres) / dune (mèches dans le vent) / écume (manches trop longues). T3 = neuf résolutions (torchon, mains, pas hors des gouttes ; bandeau, serviette, tenir le seau ; manches, Mila tient la pelle, nouer les poignets). On bâtit ensemble, sans slogan. Fin : le phare tient, on rentre le sel aux doigts.
