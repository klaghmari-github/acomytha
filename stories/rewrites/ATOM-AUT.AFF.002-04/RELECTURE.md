# ATOM-AUT.AFF.002-04 — Les carottes d'Amir

## Promesse narrative

La cuillère en bois tient dans un verre, près de l'évier. Un éclat de cuillère pâle brille sur le bois. La casserole fume, trop claire. Amir veut des carottes orange, maintenant. Il court sans le manteau : l'air pique, le sac tombe. Papa s'accroupit. Manteau vert, jardin, fanes trop vertes. Le sac cache le crochet. Amir refuse de foncer. L'éclat penche vers le crochet. Il reprend le manteau. Au marché, les carottes. Dans le verre, l'éclat porte une trace orange.

## Arc dramatique

- Monde : cuisine (verre, évier, buée), coin du tuyau au jardin, étal orange du marché.
- Désir : porter des carottes à la soupe trop claire, maintenant.
- Objet : sac de toile, manteau vert, botte de carottes.
- Indice unique : éclat de cuillère, vu dès l'ouverture, payé au climax (il penche vers le crochet) et dans le verre (trace orange).
- Urgence douce : la soupe attend l'orange ; le froid à la porte.
- Imprévu 1 : courir sans manteau ; sangle, sac à terre, poignets piqués.
- Cue : papa à la même hauteur. Un merci vécu, après le manteau repris tout seul.
- Imprévu 2 (plus rusé) : le sac cache le manteau, la buée cache le crochet ; Amir veut tirer et sortir.
- Résolution : il refuse de foncer, lit l'éclat, pousse le sac, enfile le manteau. L'étal orange, les carottes dans le sac.
- Retour : chaussures, crochet, rond orange dans la vapeur, l'éclat porte une trace orange.
