# TREE-DIF-041 — Le pain tiède d'Amir, jusqu'à la mer

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Amir veut montrer la mer à Nina depuis le wagon. T1 = vitre (champs) / tablette (pain) / porte (vent) : le voyage change. T2 = carnet (vache à finir) / pomme (pas prête) / sifflet (elle écoute). T3 = neuf résolutions : attendre, proposer tout bas, dessiner à côté ; attendre la pomme, proposer le pain, garder le sien (accepter le non) ; écouter ensemble, petit jeu, plus tard. La leçon se vit : il propose, il accepte oui, non, ou une autre idée. Fin : mer, pain tiède, sel.
