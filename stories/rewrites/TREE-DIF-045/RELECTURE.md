# TREE-DIF-045 — Le galet peint d'Aniss et le poisson de la classe

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Aniss veut poser son galet peint dans le bac à poisson de la classe. T1 = galet / épuisette / torchon (les trois partent). T2 = bac (verre trop haut) / évier (eau trop vite) / bac à sable de la cour (bleu mêlé). T3 = neuf résolutions (chaise, tendre le galet, marchepied ; eau, épuisette, robinet ; tamis, mains de Sarah, seau). Aniss répond avec les mains, sans étiquette. Sarah attend, tend. Fin : le galet est au fond, le poisson tourne, on rentre.
