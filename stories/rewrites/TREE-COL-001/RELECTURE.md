# F-NAR-015 — TREE-COL-001 (texte, archive)

Relu : les **86** chunks, les **13** questions de choix, les **3** questions d’écoute, les **27** fins, libellés d’options, `meta.characters`.

## Vu et corrigé

- Désir ≠ leçon : Raphaël veut **donner des pommes à Mila**. La politesse arrive quand quelqu’un entre, quand on demande, quand on reçoit.
- Ouverture casserole / marché / torchon / bol jaune, puis « en ce moment ». Pas de récitation des trois mots avant l’arrivée de Mila.
- Personnages D16 : **Raphaël, Mila, papa, maman**. Plus de Sami / Tom / Léa dans le récit.
- Libellés d’options du 2ᵉ choix : `Tom | Léa | Sami` (orphelins) → `la table | la fenêtre | le tabouret` (alignés sur le texte et les `next_chunk`). Topologie inchangée.
- Pas de « bravo / les trois mots » en refrain.
- Branches : train / bus / voiture changent le jeu ; table / fenêtre / tabouret changent l’installation ; matin / sieste / soir changent lumière, rythme, fin.
- Chaîne Q : train → `bonjour` ; bus → `s'il te plaît` ; voiture → `merci`. Relances alignées.
