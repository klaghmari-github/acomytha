## Vécu

T2 = four trop fort / file trop vite / banc trop agité. T3 = neuf résolutions (attendre, reculer, derrière la farine ; son tour, le bord, répéter ; pigeon, s'asseoir, l'ombre). La leçon (plus de temps, plus de calme) se vit dans les gestes, sans slogan. Fin : le pain rentre, encore tiède.
