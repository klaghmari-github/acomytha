## Promesse narrative

Le four rend un nuage de vanille. La vitre donne sur le balcon. Un petit gâteau repose sur la grille. Sur un fil, un éclat de grille brille. Amir veut un rond de raisins **maintenant**, avec Sarah. Il tend trop vite : elle dit non, le raisin roule, l'éclat saute. Sourire parti, épaules basses. Papa s'accroupit. Il veut lui mettre le raisin dans la main. Question. Il pousse trop vite : elle retire la main. Il refuse de foncer, écoute le tic, retrouve l'éclat, propose. Elle regarde. Merci vécu. Papa porte la grille au balcon. Il pousse le bol : le gâteau glisse. Il refuse, attend le silence. Elle pose un raisin, s'arrête. Il accepte, pose le dernier. L'éclat de grille tient. Trace de doigt.

## Arc dramatique

- Monde : four, vanille sur la vitre, air du balcon, table tiède, grille qui tique, raisins collants, barrette bleue.
- Désir : un rond de raisins autour du gâteau, avec Sarah, maintenant.
- Objet : gâteau, grille, fil, bol, raisins.
- Indice unique : éclat de grille, vu dès l'ouverture, payé à la fin.
- Urgence douce : le gâteau est tiède, Sarah vient d'arriver.
- Imprévu 1 : il tend trop vite ; Sarah dit non ; le raisin roule ; l'éclat saute.
- Cue : papa à la même hauteur, une question. Un merci vécu.
- Imprévu 2 (plus rusé) : pousser le bol ; le gâteau glisse d'un fil ; Sarah se tait.
- Résolution : il refuse de foncer, propose, accepte je regarde, plus tard, le silence.
- Retour : rond fini sur le balcon, éclat du début, trace de doigt.

## Vécu

Amir veut le rond **maintenant**, avec Sarah. Impatience, puis épaules qui tombent quand elle dit non. Papa s'accroupit, pose une question, ne récite pas la règle. Amir agit : il propose, accepte « je regarde », attend. Merci vécu après le regard jusqu'au bout. Fin : l'éclat du début tient sur le fil, près du rond.
