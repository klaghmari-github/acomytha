# ATOM-AUT.AFF.001-04 — Le bateau de Mila

Réécriture éditoriale F-NAR-019, example4 v2. `chunk_id` / `kind` inchangés. Texte seulement. Pas d'apply. Pas de git. Pas d'audio.

## Promesse narrative

Le bois du quai tape sous le plancher de l'appartement. Un éclat de corde pâle, raide, sent le sel sur le rebord. Mila veut porter son dessin jaune jusqu'au bateau bleu, maintenant. Elle pousse tout dans le sac d'un coup : le zip mord, le bateau se plie. Maman s'accroupit. Une chose, puis la suivante. Un souffle glisse le dessin vers la fenêtre. Mila refuse de foncer. L'éclat penche : c'est le vent. Elle ferme, glisse l'éclat, puis le dessin. Sur le bois du bateau, l'éclat porte une trace de sel.

## Arc dramatique

- Monde : appartement au-dessus du quai, savon et sel, mouette, rebord, bateau bleu en bas.
- Désir : porter le dessin jusqu'au vrai bateau, maintenant.
- Objet : sac bleu, dessin jaune, gourde, pomme, doudou.
- Indice unique : éclat de corde, vu dès l'ouverture, payé au climax et sur le bateau.
- Urgence douce : le bateau tape, le vent peut prendre le dessin.
- Imprévu 1 : tout d'un coup, zip qui mord, dessin plié.
- Cue : maman à la même hauteur, une chose puis la suivante. Un merci vécu, après le dessin rangé.
- Imprévu 2 (plus rusé) : le souffle vers la fenêtre ; Mila veut descendre sans le sac.
- Résolution : elle refuse de foncer, lit l'éclat, ferme, glisse l'éclat puis le dessin. Une corde mouillée frappe un anneau au quai.
- Retour : pied sur le bois, on flotte, l'éclat a une trace de sel, le dessin reste plat.
