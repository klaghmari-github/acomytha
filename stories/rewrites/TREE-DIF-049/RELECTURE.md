# TREE-DIF-049 — Les poissons de papier de Sarah, sur le tapis

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Sarah veut une pêche sur le tapis du salon, pour Nino. T1 = bâton (canapé, rive haute) / seau bleu (table, port) / poisson jaune (tapis tiède) : le voyage change. T2 = boîte à musique (chanson à finir) / camion jaune (pas garé) / chaussons (un pied nu). T3 = neuf résolutions : attendre la chanson, proposer tout bas, s'asseoir ; laisser garer, un poisson dans le camion, garder le seau (accepter le non) ; aider le chausson, un tout petit regard, plus tard. La leçon se vit : elle propose, elle accepte oui, non, ou une autre idée. Fin : poissons jaunes, seau, ficelle.
