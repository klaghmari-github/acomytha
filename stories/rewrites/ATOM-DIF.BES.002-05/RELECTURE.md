## Promesse narrative

La cheminée boit le vent. Sur la brique, un éclat de cheminée brille. Un carton ouvert attend dans le couloir. Voiture rouge, phare jaune. Chouchou veut le garage **maintenant**, avec Mila. Elle tire trop vite, attrape la manche : non. Le rabat est dur, la voiture tape le bord, l'éclat glisse. Sourire parti. Papa s'accroupit. Elle refuse de foncer, propose. Mila regarde. Merci vécu. Deuxième ruse : la voiture file trop vite. Elle refuse, retrouve l'éclat, propose le rabat. Plus tard. Toc. Le rabat se ferme. L'éclat tient.
