# TREE-DIF-067 — Le seau rond de Nino, au puits

Relu : monde, désir, imprévu, question, résolution, fin heureuse. `chunk_id` / `kind` inchangés.

## Vécu
Puits du village, mousse froide, seau qui cliquette, ombre d'eau. Nino veut remonter de l'eau pour la bassine de maman, avec le bon seau. T1 = seau rond de bois / seau mince en zinc / corde rêche (les trois partent). T2 = margelle trop glissante / auge trop basse / treille qui accroche. T3 = neuf gestes (seau rond, tenir le mince, attendre ; à deux, la corde, poser le rond ; décrocher, attendre, à deux). La leçon se vit : le rond tient, le mince penche, l'eau arrive quand même. Fin : l'eau tremble dans la bassine, on rentre.
