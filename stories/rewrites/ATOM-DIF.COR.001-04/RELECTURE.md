## Promesse narrative

Le fil à linge fait tic dans la cour. La chaleur pique les pieds. Un drap blanc pend au soleil. Une feuille colle au cerceau rouge. Sur le fer, un éclat de cerceau brille. Nina veut un tunnel pour la voiture **maintenant**. Première idée : saisir le cerceau d'un coup. Il roule dans les feuilles. Sourire parti, épaules basses. Papa s'accroupit. Aniss arrive. Elle invite. Il se tait, puis oui. Elle tient trop haut : ses doigts glissent. Il dit Attends. Ils tiennent le fer, haut et bas. Question. Le drap fait grotte. Elle pousse trop vite : le drap glisse. Elle refuse de foncer, écoute le tic, retrouve l'éclat. Aniss pose une main, sans parler. La voiture passe. Merci vécu. Elle lève trop haut : l'éclat manque. Elle refuse, baisse le fer. L'éclat de cerceau tient sur le fer.

## Arc dramatique

- Monde : cour, fil à linge qui tique, chaleur, drap au soleil, feuille sur le cerceau rouge, voiture à l'ombre, platane.
- Désir : un tunnel pour la voiture, avec Aniss, maintenant.
- Objet : cerceau rouge, drap, voiture de bois, fil à linge.
- Indice unique : éclat de cerceau, vu dès l'ouverture, payé à la fin.
- Urgence douce : le drap est chaud, Aniss vient d'arriver.
- Imprévu 1 : elle saisit trop vite ; le cerceau roule ; trop haut, les doigts d'Aniss glissent.
- Cue : papa à la même hauteur, une question. Un merci vécu.
- Imprévu 2 (plus rusé) : lever le fer trop haut ; le drap glisse ; l'éclat manque ; Aniss dit Attends.
- Résolution : elle refuse de foncer, baisse le cerceau, Aniss tient le bas, deux mains sur le drap.
- Retour : cerceau contre le mur, feuille collée, éclat du début, drap qui sent le soleil.

## Vécu

Nina propose, veut **maintenant**. Aniss prend son temps, pose une limite, se tait. Le silence compte. Papa s'accroupit, ne récite pas « jouer ensemble ». La leçon se voit : deux hauteurs, deux mains, la voiture qui passe. Merci vécu après les deux mains sur le drap. Fin : l'éclat du début tient sur le fer.
