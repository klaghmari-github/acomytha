TREE-AUT-001-R1 — Le bateau d’Amir et la flaque

Leçons : AUT.AFF.001 (préparer le sac) · AUT.AFF.002 (prendre le manteau)

Âge N1 · papa, maman, Amir · framing standard
P0000 — début
Sur le toit, la gouttière fait encore plic ploc.

La pluie vient de s’arrêter.

Le volet jaune claque tout doux.

Dans la rue, les pavés brillent.

Une odeur de soupe entre par la fenêtre.
Dans la chambre, le tapis est rayé, bleu et crème.

Un rayon de soleil touche le plancher.
Amir a un bateau en papier.

Une voile pliée. Un peu froissée.
— Papa, la flaque est là, dans le jardin.

— Oui. On y va quand le sac est prêt.
Le sac attend sur le tapis.

Amir tire la fermeture. Zzz.

Le sac est vide.

Le bateau est sur la commode.
Q1 — au moment du besoin

Où Amir met-il le bateau ?

Attendu : « dans le sac » / « le sac ».

Silence → la narration reprend, sans verdict.
Amir glisse le bateau au fond.

Toc.

La voile dépasse un tout petit peu.

Il la rentre avec le doigt.
T1 — choix narratif (tous sûrs)

Pour aller à la flaque, on prend aussi…

le manteau
les bottes
un linge

Branche 1 — le manteau

Le manteau est sur la chaise.

Il est encore un peu chaud.

Papa le tend.

Amir le plie.

Il le met dans le sac, à côté du bateau.
Branche 2 — les bottes

Les bottes sont près de la porte.

Elles sont encore mouillées dehors.

Maman les essuie.

Amir les pose à côté du sac.

On les mettra au pied, juste avant de sortir.
Branche 3 — le linge

Le linge est sur le radiateur.

Il sent le propre.

Amir le roule.

Il le glisse près du bateau.

Pour sécher les mains, après la flaque.
P milieu — on ferme
Amir tire la fermeture. Zzz.

Le sac est lourd d’un côté.

Le bateau est dedans.
— C’est bon, papa.

— Alors on y va.
Q2

Qui ferme le sac ?

Attendu : « Amir ».
T2 — dans le jardin

La flaque est ronde, près du potager.

L’eau tremble un peu.
On pose le bateau…

au milieu de l’eau
près du bord, avec papa
d’abord sur le sac, pour regarder

(Les trois fins arrivent au même geste : le bateau flotte, on rentre le sac.)
Fin A

Amir pose le bateau au milieu.

La voile se tient.

Un peu d’eau touche le papier.

Papa reste à côté.

— Il avance.

Amir souffle. Ffff.

Le bateau part tout doux.
Fin B

Amir donne le bateau à papa.

Papa le pose près du bord.

Amir tient le sac.

Le bateau part.

Amir marche le long de l’eau, le sac à l’épaule.
Fin C

Amir pose d’abord le sac.

Il pose le bateau sur le sac.

Il regarde la flaque.

Puis il met le bateau dans l’eau.

Papa dit : — Tu as préparé. Maintenant il flotte.
Fermeture (toutes les feuilles)
Le papier est un peu mouillé.

Amir reprend le bateau.

Il le remet dans le sac.

Le manteau, les bottes ou le linge rentrent aussi.
On referme. Zzz.

La gouttière fait un dernier plic.
L’histoire est finie.
